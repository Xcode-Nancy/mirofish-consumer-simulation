# Raw Dataset Instructions

The original Datafiniti Amazon Consumer Reviews datasets are not
included in this repository because of their size and unverified
redistribution permissions.

Obtain the datasets from their original authorized source.

Place the following files in this directory:

1. 1429_1.csv
2. Datafiniti_Amazon_Consumer_Reviews_of_Amazon_Products.csv
3. Datafiniti_Amazon_Consumer_Reviews_of_Amazon_Products_May19.csv

The CSV files are intentionally excluded from Git through .gitignore.

Before redistribution, verify the original dataset licensing and
attribution requirements.

See ../../data/source_registry.csv for the dataset inventory,
metadata and SHA-256 checksums.
